## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder hasil ekstrak.
3. Klik dua kali `index.html`.
4. Karena Bootstrap menggunakan CDN, komputer membutuhkan koneksi internet saat pertama membuka website.

## Sebelum dikumpulkan
1. Ganti `emailkamu@example.com` dengan email asli.
2. Ganti `@username` dengan username Instagram jika diperlukan.
3. Tambahkan link GitHub pada bagian project jika sudah tersedia.
4. Screenshot website jika diminta guru.

## GitHub Pages
Setelah repository GitHub dibuat:
1. Upload `index.html`, `style.css`, dan `script.js`.
2. Masuk ke **Settings → Pages**.
3. Pada Source pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/root`.
5. Simpan dan tunggu proses deploy.
6. Link yang muncul adalah link live demo GitHub Pages.
